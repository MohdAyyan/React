# Task Management System with Firebase

## 🚀 Overview
A modern task management system with user authentication and admin capabilities built using React 

## ✨ Features
- Admin Dashboard
- Task Creation and Management
- Real-time Updates
- Responsive Design

## 🛠️ Tech Stack
- React.js 18
- Bootstrap
- React Router DOM
- React Toastify

## 📦 Installation
1. Clone the repository
```bash
git clone <repository-url>
cd 18Project
```

2. Install dependencies
```bash
npm install
```



3. Start the development server
```bash
npm start
```

## 👥 Features
- **Admin Dashboard**: Complete task management
- **User Authentication**: Secure login and registration
- **Task Management**: Create, read, update, and delete tasks
