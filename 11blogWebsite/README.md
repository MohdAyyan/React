# Blog Website

A simple and modern blog website built with react and appwrite.

## Features

- Responsive design that works on desktop, tablet, and mobile devices
- Article listings with pagination
- Comment system with real-time updates
- User authentication (login/register)
- Search functionality with filters
- Categories and tags for better content organization
- Rich text editor for creating posts
- Social media sharing integration

## Technology Stack

- HTML5
- CSS3 (with Flexbox/Grid)
- JavaScript (ES6+)
- React.js for UI components
- Appwrite Services Authentication

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/11blogWebsite.git
```

2. Install dependencies:
```bash
cd 11blogWebsite
npm install
```

3. Set up environment variables:
- Create a `.env` file in the root directory
- Add necessary environment variables:
```
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

4. Start the development server:
```bash
npm run dev
```

## Usage

1. Register a new account or login with existing credentials
2. Create, edit, and delete blog posts
3. Comment on articles
4. Search for specific content
5. Filter articles by categories or tags
